# Third-party material inventory
Faceless Shorts is a user-installed source snapshot. Its top-level redistribution
license is not declared in the inspected source. This document grants no rights.

Preserved notices include LICENSE-three.txt under the deep-dive, night-file and
tall-tale example/vendor folders. Example font files include Inter-Black.otf and
FreeMonoBold.ttf where provided; verify the matching license/attribution terms before
redistribution. Do not assume the surrounding skill's licensing covers these assets.

Kokoro/Whisper weights are runtime downloads and are not included in this package.
Review each model license and required attribution at the selected pinned revision.
Review FFmpeg build configuration and linked codec licenses separately. A release
must record exact versions, sources, hashes and notices for every shipped binary,
font, model and vendored dependency. Existing vendor notices were not removed.
